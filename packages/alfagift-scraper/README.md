# Alfagift Scraper (`alfagift-scraper`)

Standalone Python scraper for products, categories, pricing, and stock details from the **Alfamart Alfagift** e-commerce app API.

## 🚀 Quick Start

```bash
# Install via pip
pip install alfagift-scraper

# Run Alfagift scraper CLI
alfagift-scraper --output data/alfagift.json
```
