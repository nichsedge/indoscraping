# IndoScraping Core (`indoscraping-core`)

Shared engine, anti-bot mimicry, data quality validators, and export utilities for the IndoScraping ecosystem.

## 📦 Features

- **Data Quality (`indoscraping.core.dq`)**: Schema validation, required key verification, and duplication checks.
- **Lineage & Metadata (`indoscraping.core.lineage`)**: Automated tracking for dataset provenance and crawling run metrics.
- **Output Handlers (`indoscraping.core.output`)**: Standardized JSON/CSV exports and data formatting.
